# Журнал изменений

Все заметные изменения проекта документируются в этом файле.
Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии — [SemVer](https://semver.org/lang/ru/).

## [Unreleased]

### Исправлено (по итогам независимого ревью)
- Запись на целые сутки (`0000 2400`) не открывалась на редактирование («Нулевая длительность»): в форме и диалоге 00:00–00:00 теперь означает сутки.
- Цифры не из ASCII (`０９００`) вызывали исключение вместо понятной ошибки разбора.
- `--data-dir` без пути молча открывал стандартную папку данных — теперь сообщение об ошибке и код выхода 1; код выхода приложения передаётся ОС.

### Добавлено
- Экран «Журнал»: быстрый ввод с живым предпросмотром, многострочная вставка, форма с выбором даты и времени, сводка «Сегодня · Неделя», список по дням, поиск по комментариям, редактирование, удаление с отменой (F1, F2, F3.4, F5, F6, F7.2).
- Экран «Статистика»: день / неделя / месяц / год / всё время / произвольный период, 8 показателей, графики по дням и месяцам, среднее по дням недели, тепловая карта года, экспорт CSV (F3).
- Экраны «Настройки» (норма, рабочие дни, тема, папка данных, резервная копия, экспорт) и «О программе» (F7.4, F7.5).
- Боковая навигация, горячие клавиши `Enter`, `Ctrl+Z`, `Del`, `Ctrl+F`, `Ctrl+1…4`, `Esc` (F7.3, F7.6).
- Светлая и тёмная темы, запоминание размера и положения окна (F7.8, F4.8).
- Журнал программы (Serilog) и дружелюбные сообщения об ошибках (F7.10).
- Хранилище SQLite: миграции схемы, мягкое удаление с очисткой через 30 дней, поиск по комментариям без учёта регистра (включая кириллицу), настройки (F4, F5.3, F6.4).
- Резервные копии: автоматически раз в день и вручную, хранятся 14 последних (F4.5).
- Портативный режим (`portable.txt` рядом с exe) и параметр `--data-dir` (F4.2, F4.3).
- Полноценный режим `--self-test` без UI (F7.11).
- Разбор быстрого ввода `[дата] начало–конец [комментарий]` с ночными сменами, `сейчас`/`now`, многострочной вставкой и понятными ошибками (F1).
- Запрет пересечений записей с учётом соседних дней (F7.1).
- Расчёт статистики: итого, средние, норма и баланс, сравнение с предыдущим периодом, ряды для графиков (F3.2, F3.3).
- Экспорт в CSV для русского Excel (F3.5).
- Решение `WorkTimeTracker.slnx`: проекты Core / Data / App, три тестовых проекта, утилита `tools/IconGen`; Central Package Management, lock-файлы, `global.json` (.NET 10).
- Окно Avalonia с боковой навигацией; режимы командной строки `--version`, `--self-test`, `--data-dir` (F7.11).
- CI в GitHub Actions: тесты и покрытие на Linux, публикация и self-test настоящего Windows-exe.
- Скрипты `scripts/build.sh`, `test.sh`, `run.sh`, `publish-win.sh`.
- Инфраструктура проекта: лицензия MIT, `.gitignore`, `.gitattributes`, `.editorconfig`, журнал разработки и чек-лист прогресса.
