# Формат быстрого ввода

Однострочное поле на экране «Журнал» (F1). При запуске фокус стоит в нём, `Enter` добавляет запись.
Реализация — `src/WorkTimeTracker.Core/Parsing/QuickEntryParser.cs`, тесты — `tests/WorkTimeTracker.Core.Tests/QuickEntryParser*Tests.cs`.

## Грамматика

```
[дата] <начало> <разделитель> <конец> [комментарий]
```

| Часть | Формы | Примеры |
|---|---|---|
| **Дата** (необязательно, только первым словом) | `dd.MM`, `dd.MM.yyyy` (день и месяц — 1–2 цифры) | `15.03`, `1.1`, `15.03.2025` |
| **Время** (начало и конец) | `HHmm`, `Hmm`, `H`, `HH`, `H:mm`, `HH:mm`, `сейчас`, `now` | `0930`, `930`, `9`, `09`, `9:30`, `09:30` |
| **Разделитель** | один или несколько пробелов и/или одно тире: `-`, `–`, `—` (вокруг тире могут быть пробелы) | `0900 1800`, `0900-1800`, `0900 — 1800` |
| **Комментарий** | весь остаток строки, пробелы по краям обрезаются; до 500 символов | `созвон с клиентом` |

Регистр слов `сейчас`/`now` не важен. Табуляция считается пробелом.

## Правила

1. **Без даты** берётся дата, выбранная в интерфейсе (по умолчанию — сегодня).
2. **Дата без года** (`dd.MM`) — текущий год; если такая дата в текущем году ещё не наступила, берётся прошлый год. В январе `28.12` — это прошлый декабрь.
3. **Время с точкой** (`09.30`) не поддерживается: точка зарезервирована для даты. `09.30 1800` распознаётся как дата «9 число 30-го месяца» и даёт ошибку «Несуществующая дата» с подсказкой.
4. **`сейчас` / `now`** — текущее время по часам компьютера с точностью до минуты (секунды отбрасываются).
5. **Конец раньше начала** — ночная смена: конец приходится на следующие сутки, запись относится к дате **начала**. `2200 0200` = 4 ч.
6. **`2400` / `24:00` / `24`** допустимо только как время окончания — конец суток. `0000 2400` = 24 ч. Конец `0000` при ненулевом начале тоже означает полночь: `2300 0000` = 23:00–24:00.
7. **Длительность** больше 0 и не больше 24 ч (по построению ночной смены она всегда < 24 ч, ровно 24 ч — только `0000 2400`).
8. **Даты в будущем запрещены** (запись — факт, а не план). Время окончания сегодняшней записи может быть позже текущего момента — это не проверяется.
9. **Второй интервал в одной строке** запрещён. Если комментарий начинается с токена, похожего на время, — ошибка. «Похож на время»: 3–4 цифры (`1400`), `H:mm` (`14:00`), или 1–2 цифры, за которыми через пробел/тире идёт ещё одно число (`14 18`, `14-18`). Сразу после времени окончания не может идти тире (`0900 1300-1400`). Комментарий вроде `3 задачи` допустим.
10. **Пересечения** с другими записями запрещены (F7.1) — проверяются при добавлении, см. ADR-0007.

## Форма и редактирование (F2, F6.3)

Форма и диалог редактирования используют те же правила (`EntryService.BuildDraft` → `EntryRules`). В `TimePicker` нет «24:00», поэтому:
- конец `00:00` при ненулевом начале — полночь (как `2300 0000`);
- `00:00 – 00:00` — **целые сутки** (как `0000 2400`). Так же открывается в диалоге редактирования запись `0000 2400`.

## Многострочная вставка (F1.2)

При вставке нескольких строк каждая непустая строка — отдельная запись. Добавление **атомарное**: если хоть одна строка невалидна или пересекается с другой записью (в том числе со строкой из той же вставки), не добавляется ничего. Ошибки показываются построчно, номера — физические номера строк, считая пустые:

```
Строка 2: Часы должны быть от 0 до 23 — «2500»
Строка 3: Не указано время окончания
```

Если непустая строка одна, префикс «Строка N:» не пишется.

## Живой предпросмотр (F1.3)

Под полем при наборе показывается результат разбора:

- `✓ 10 нояб. · 09:00 → 18:00 · 9 ч 00 мин · «созвон»`
- `✓ 10 нояб. · 22:00 → 02:00 +1 · 4 ч 00 мин` (ночная смена)
- `✗ Часы должны быть от 0 до 23 — «2500»` — красным, с проблемным фрагментом.

Кнопка «Добавить» и `Enter` недоступны, пока ввод невалиден. `Esc` очищает поле.

## Тексты ошибок

| Ситуация | Сообщение | Пример ввода |
|---|---|---|
| Пустая строка | — (игнорируется) | `   ` |
| Нулевая длительность | Нулевая длительность | `1800 1800` |
| Часы вне 0–23 (кроме 24:00 в конце) | Часы должны быть от 0 до 23 | `2500 1800`, `2430 0100` |
| Минуты вне 0–59 | Минуты должны быть от 0 до 59 | `0960 1800` |
| 24:00 в начале | 24:00 допустимо только как время окончания | `2400 0100` |
| Нет конца | Не указано время окончания | `0900`, `0900 -` |
| Есть дата, но нет времени | Не указано время начала | `15.03` |
| Начало — не время | Не удалось распознать время начала | `abc`, `+0900 1800` |
| Конец — не время | Не удалось распознать время окончания | `0900 abc` |
| Неверное число цифр или формат | Неверный формат времени: `<фрагмент>` | `12345 1800`, `9:5 18`, `0900abc 1800` |
| Цифры не из ASCII (полноширинные, арабо-индийские) | Не удалось распознать время начала / окончания | `０９００ １８００` |
| Время с точкой | Время с точкой не поддерживается — пишите 09:30 или 0930 | `9.30-18.00` |
| Второй интервал | Похоже на второй интервал — вводите каждый интервал с новой строки | `0900 1300 1400 1800` |
| Несуществующая дата | Несуществующая дата | `31.02 0900 1000`, `29.02.2025 …` |
| Дата в будущем | Дата в будущем | `11.11.2026 0900 1000` (сегодня 10.11.2026) |
| Длинный комментарий | Комментарий длиннее 500 символов | — |
| Пересечение | Пересекается с записью 10.11 13:00–15:00 «обед» | — |

## Примеры

«Сегодня» — 10.11.2026, 14:37.

| Ввод | Результат |
|---|---|
| `0900 1800` | 10.11, 09:00–18:00, 9 ч 00 мин |
| `900 1800`, `9 18` | 09:00–18:00 |
| `09:00 18:30` | 09:00–18:30, 9 ч 30 мин |
| `9:05-13:40` | 09:05–13:40 |
| `0900 - 1800`, `0900—1800` | 09:00–18:00 |
| `0900 1800 созвон с клиентом` | комментарий «созвон с клиентом» |
| `2200 0200` | 10.11 22:00 → 11.11 02:00, 4 ч, дата записи 10.11 |
| `0000 2400` | 00:00–24:00, 24 ч |
| `15.03 0900 1800 отчёт` | 15.03.2026, комментарий «отчёт» |
| `28.12 1000 1200` | 28.12.2025 (в 2026 году эта дата ещё впереди) |
| `15.03.2025 0900 1800` | 15.03.2025 |
| `0900 сейчас` | 09:00–14:37 |
