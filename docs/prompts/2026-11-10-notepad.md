## 1. Суть фичи

**Блокнот** — это рабочий лист поверх общих данных.

- Запись, добавленная во вкладке «Блокнот», — **обычная запись**: она сразу попадает в «Журнал» и в «Статистику».
- Блокнот помнит, какие записи добавили через него, и показывает их **сумму**.
- Кнопка **«Очистить всё»** убирает записи из блокнота, переносит лист в **архив** и не трогает сами записи: в «Журнале» и «Статистике» они остаются.
- «Журнал» и «Статистика» работают **как раньше**. Статистика про блокнот ничего не знает.

## 2. Требования (ID — F8.x, используй их в коммитах, тестах и `docs/FEATURES.md`)

### Вкладка и ввод
- **F8.1 Новая вкладка «Блокнот» — вторая в навигации.** Горячие клавиши: `Ctrl+1` Журнал, `Ctrl+2` **Блокнот**, `Ctrl+3` Статистика, `Ctrl+4` Настройки, `Ctrl+5` О программе. Обнови подсказки, README и документацию.
- **F8.2 Добавление** — тот же контрол быстрого ввода и та же форма, что в «Журнале»: формат (F1), предпросмотр, вставка нескольких строк (атомарно), `Enter`.
- **F8.3 Проверка пересечений** — со **всеми** записями базы, а не только с записями блокнота.
- **F8.4 Атомарность:** создание записи и её привязка к листу блокнота выполняются в **одной транзакции**. Запись не может оказаться в статистике, но не в блокноте, или наоборот.
- **F8.5 Записи, добавленные через «Журнал», в блокноте не появляются.**

### Плашка и лист
- **F8.6 Плашка суммы:** «В блокноте: 7 ч 30 мин · 2 записи · ведётся с 10 нояб., 09:12». Сумма считается как в статистике (ночная смена — целиком). Обновляется сразу при любом изменении, в том числе из «Журнала».
- **F8.7 Название листа (необязательное):** редактируется прямо на плашке, до 100 символов, плейсхолдер «Без названия». Пример: «Заказ: сайт кафе».
- **F8.8 Порядок записей:** по дате и времени начала, как в табеле. В каждой строке видна дата.
- **F8.9 Сохранение:** блокнот, его название и архив переживают перезапуск. Очищается блокнот только кнопкой.

### Действия с записями в блокноте
- **F8.10 Правка (✎)** меняет **саму запись** (диалог и валидация те же, что в «Журнале»), поэтому изменение видно везде.
- **F8.11 Кнопка ✕ / клавиша `Del` / пункт контекстного меню во вкладке «Блокнот» убирают запись только из блокнота.** Запись остаётся в «Журнале» и «Статистике». Подсказка на кнопке: «Убрать из блокнота (запись останется в журнале и статистике)». Есть множественный выбор (`Ctrl`/`Shift`) и отмена (уведомление на 8 секунд + `Ctrl+Z`).
- **F8.12 Удаление в «Журнале» удаляет запись отовсюду**, включая текущий блокнот и архив; отмена в «Журнале» возвращает её на место. Подсказку кнопки удаления в «Журнале» дополни: «Удалить запись (в том числе из блокнота)».
- **F8.13 Полного удаления записи во вкладке «Блокнот» нет** — это сделано намеренно.

### Очистка и архив
- **F8.14 «Очистить всё»** — лист закрывается и уходит в архив, список и сумма обнуляются, записи остаются в «Журнале» и «Статистике».
  - Диалога подтверждения нет; вместо него уведомление «Блокнот перенесён в архив · Отменить» (8 секунд) и `Ctrl+Z`.
  - Отмена доступна до следующего изменения в блокноте.
  - Когда блокнот пуст, кнопка неактивна.
- **F8.15 Архив:** переключатель вверху вкладки «Текущий | Архив (N)». Список прошлых листов, новые сверху. Карточка листа:
  - название (или «Лист 3–6 нояб.», если названия нет);
  - диапазон дат записей;
  - сумма и количество записей;
  - «очищен 6 нояб., 18:40».

  Клик раскрывает список записей листа, только для чтения.
- **F8.16 Архив «живой»:** показывает текущее состояние записей, а не снимок. Если запись исправили или удалили в «Журнале», это видно и в архиве. Лист, все записи которого удалены, остаётся в архиве с пометкой «записи удалены».
- **F8.17 «Удалить из архива»** удаляет только лист, записи остаются в «Журнале» и «Статистике». Работает отмена (уведомление + `Ctrl+Z`).
- **F8.18 Очистка мусора при запуске**, по тому же правилу, что для записей (старше 30 дней): физически удаляются убранные из блокнота привязки и удалённые из архива листы.

### UX
- **F8.19 Пустые состояния:**
  - текущий блокнот: «Блокнот пуст — запишите время, например `0900 1800 задача`. Записи попадут и в журнал, и в статистику.»;
  - архив: «Здесь появятся очищенные блокноты».
- **F8.20 Отмена по `Ctrl+Z`** действует на последнее действие **активной вкладки**. Если текущая реализация отмены глобальная, адаптируй её и запиши решение в ADR.

## 3. Модель данных (новая миграция — следующий номер после существующих)

Таблицу `entries` **не меняем**: блокнот — отдельная сущность поверх записей (ADR-0009).

```sql
CREATE TABLE notepad_sheets (
    id          INTEGER PRIMARY KEY AUTOINCREMENT,
    title       TEXT    NOT NULL DEFAULT '' CHECK (length(title) <= 100),
    started_at  TEXT    NOT NULL,      -- UTC: создание листа (первая запись или ввод названия)
    cleared_at  TEXT    NULL,          -- UTC: «Очистить всё»; NULL = текущий лист
    deleted_at  TEXT    NULL           -- удалён из архива (мягко, для отмены)
);

CREATE TABLE notepad_items (
    entry_id    INTEGER PRIMARY KEY REFERENCES entries(id) ON DELETE CASCADE,  -- запись — максимум в одном листе
    sheet_id    INTEGER NOT NULL REFERENCES notepad_sheets(id) ON DELETE CASCADE,
    added_at    TEXT    NOT NULL,      -- UTC
    removed_at  TEXT    NULL           -- убрана из блокнота кнопкой ✕ (мягко, для отмены)
);
CREATE INDEX ix_notepad_items_sheet ON notepad_items(sheet_id);
```

**Инварианты (покрыть тестами):**
- Текущий лист (`cleared_at IS NULL AND deleted_at IS NULL`) — не больше одного. Создаётся лениво: при первом добавлении записи или при вводе названия.
- Видимые записи листа: `notepad_items.removed_at IS NULL` и `entries.deleted_at IS NULL`.
- Отмена «Очистить всё» = `cleared_at = NULL`. Она возможна только если новый текущий лист ещё не создан.
- Ни одна операция блокнота **никогда** не меняет и не удаляет строки `entries`, кроме правки (F8.10) через существующий сервис записей.
