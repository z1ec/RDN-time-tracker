# Дорожная карта

Все требования P0, P1 и P2 задания реализованы в v1.0.0, вкладка «Блокнот» (F8) — в v1.1.0, блокнот-песочница (F9) — в v1.2.0 (см. `docs/FEATURES.md`). Ниже — то, что сознательно не входило в эти версии, и известные ограничения.

## Идеи на будущее (вне рамок v1.0.0 по заданию)

| Идея | Зачем | Заметки по реализации |
|---|---|---|
| Установщик (MSIX / Inno Setup) | ярлык в «Пуске», удаление через «Приложения» | exe уже самодостаточен; MSIX потребует подписи |
| Подпись кода | убрать предупреждение SmartScreen | нужен сертификат издателя (OV/EV) или Azure Trusted Signing; шаг подписи — в `release.yml` перед упаковкой |
| Облачная синхронизация | несколько компьютеров | проще всего — хранить `worktime.db` в синхронизируемой папке через портативный режим; полноценная синхронизация требует идентификаторов-GUID и разрешения конфликтов |
| Таймер «старт/стоп» | фиксировать время в моменте | новая сущность «открытая запись» без `end_min`; пересечения проверять при остановке |
| Проекты и теги | статистика по проектам | таблица `projects`, `entries.project_id` (новая миграция), фильтры в статистике |
| Импорт CSV | перенос данных из Excel/других трекеров | формат — тот же, что у экспорта; построчная валидация через `QuickEntryParser`/`EntryRules`, атомарно |
| Автообновление | — | противоречит принципу «офлайн, без фоновых соединений»; если делать — только по кнопке |
| Мультиязычность | англоязычные пользователи | тексты вынести в ресурсы; `RuFormat` → интерфейс форматтера на культуру |
| Версии для macOS и Linux | кроссплатформенность | Avalonia уже кроссплатформенная, нужны публикация `osx-arm64`/`linux-x64`, подпись и нотаризация для macOS |

## Идеи для блокнота (после v1.2.0)

| Идея | Зачем | Заметки по реализации |
|---|---|---|
| Вернуть лист из архива в блокнот | продолжить заказ, который уже «закрыли» | `cleared_at = NULL`, если текущего листа нет (как отмена очистки, но без ограничения по времени); если текущий лист есть — предложить сначала очистить его |
| Экспорт листа в CSV | отправить заказчику отчёт по заказу | `CsvExporter` уже умеет список записей; добавить кнопку на плашке и на карточке архива, имя файла — название листа |
| Пометка в «Журнале», что запись в блокноте | видеть, какие записи относятся к листу, и не удалить их случайно | значок в строке журнала по `notepad_lines.entry_id`; подсказка с названием листа |
| Добавить существующую запись журнала в блокнот | собрать лист из уже введённых записей | `INSERT` в `notepad_lines` со значениями записи и её `entry_id`; запись по-прежнему максимум в одной строке |
| Несколько текущих листов | вести два заказа параллельно | снять уникальный индекс «один текущий лист», выбор листа на плашке |
| ~~Повторный ввод после ✕ / прикидки с пересечениями~~ | — | сделано в v1.2.0 (F9, ADR-0010) |
| Записать строку «не в статистике», когда конфликт исчез | после удаления записи в «Журнале» строку блокнота можно было бы учесть | сейчас — правкой строки (F9.5); отдельная кнопка отвергнута пользователем в v1.2.0, автоматическая запись меняла бы статистику без действия пользователя |

## Возможные улучшения

- Праздничные и сокращённые дни в расчёте нормы (производственный календарь РФ).
- Отмена нескольких последних удалений (сейчас — только последнее, ADR-0004).
- Перенос/копирование записей на другую дату, массовое редактирование.
- Проверка пересечений при наборе (сейчас — при нажатии «Добавить»).
- Графики: масштабирование произвольного периода, сравнение двух периодов на одном графике.
- Экспорт в XLSX без «танцев» с кодировкой.

## Известные ограничения

- **Часовые пояса и летнее время не учитываются** (ADR-0003): ночная смена в ночь перевода часов считается по циферблату.
- **Ночная смена целиком относится к дате начала** — смена «вс 23:00 – пн 02:00» попадает в прошлую неделю.
- **Пересечения проверяет приложение, а не БД** (ADR-0007): ручная правка файла БД может создать пересечение.
- **Поиск** работает подстрокой без учёта регистра, но «е» и «ё» различаются.
- **Отмена** (удаления в журнале; ✕, очистки и удаления листа в блокноте) доступна только для последнего действия вкладки, только пока после него не было других изменений, и не переживает перезапуск.
- **Блокнот:** запись журнала связана максимум с одной строкой; записи, добавленные через «Журнал», в блокнот не попадают; связанная строка в архиве меняется, если запись позже исправили в журнале (ADR-0009, F9.6). Строка «не в статистике» сама не записывается в базу, даже если пересечения уже нет (ADR-0010). Проверка пересечений идёт до транзакции записи — при двух программах, одновременно пишущих в одну БД, пересечение теоретически могло бы проскочить.
- **Exe не подписан** — SmartScreen предупреждает при первом запуске (см. `docs/BUILD_AND_RELEASE.md`).
- **Размер exe ~50 МБ**: self-contained .NET + Skia без trimming (ADR-0006).
- Восстановление положения окна на конфигурациях с несколькими мониторами с разным масштабом проверено только вручную; если сохранённая позиция вне экранов, окно открывается по центру.
