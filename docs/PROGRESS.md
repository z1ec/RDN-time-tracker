- [ ] `dotnet build -c Release` — 0 предупреждений; `dotnet test` — всё зелёное; покрытие Core ≥ 90%; `dotnet format --verify-no-changes` проходит.
- [ ] CI на `main` зелёный (тесты + Windows publish + self-test настоящего exe).

- [ ] Скриншоты в `docs/images/` (светлая и тёмная темы) сгенерированы и визуально проверены.
- [ ] README полный, бейджи и ссылки рабочие (ведут на реальный репозиторий).

## Внешние блокировки

- `gh` CLI не установлен на машине разработки (2026-11-09). Нужен для проверки CI (`gh run watch`) и `gh release view`. Что сделать человеку: `brew install gh && gh auth login`. До этого статус CI проверяется через публичный REST API GitHub (`curl https://api.github.com/repos/z1ec/RDN-time-tracker/actions/runs`).
